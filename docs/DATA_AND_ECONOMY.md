Tourism is not a good. It is a **demand/income multiplier** unlocked at the charter tier.

## File Schemas (JSON in `/public/data`)
### islands.json
```json
{
  "id": "naxos", "name": "Naxos", "type": "island|mainland_port",
  "country": "GR|TR", "lat": 37.10, "lon": 25.38,
  "population": 19000, "size": "xs|s|m|l|xl",
  "region": "cyclades",
  "port": { "lat": 37.105, "lon": 25.373 },
  "produces": { "grain": 8, "cheese": 6, "water": 5 },
  "consumes": { "fuel": 4, "wine": 2, "crafts": 3 },
  "unlock": { "cost": 100, "requiresConnectedTo": ["paros"], "requiresTier": 1 },
  "tourismBase": 0.4
}
```
`produces` and `consumes` are units per game-day at baseline. The population scales consumption.

### goods.json
`{ id, name, basePrice, volume, perishable, icon, color }`

### ships.json
```json
{ "id": "fishing_boat", "tier": 1, "capacity": 20, "speed": 6, "cost": 50,
  "range": 80, "upkeep": 1, "unlock": { "islandsConnected": 2 } }
```
Tiers: fishing_boat (cap 20, short range), caique (60), ferry (passengers + 150 goods, scheduled), cargo_ship (800, long range, mainland), charter_yacht (tourism income).

### seaLanes.json
Nodes (id, lat, lon) and edges (a, b). Generated by the bake tool from a sea mask, then hand-fixed.

## Economy Rules
- **Stock** per island per good: `stock += (produce - consume) * dt`, clamped to [0, capacity].
- **Price**: `price = basePrice * clamp((target / (stock + 1)) ^ k, 0.3, 3.0)`, where `target` is the island's desired buffer and k ~ 0.7.
- **Scarcity**: stock at 0 for a needed good accrues "distress", which slows growth (visible as a dim red glow). A good surplus raises "prosperity" (brighter lights).
- **Route profit** = `capacity * (sellPrice - buyPrice) - upkeep * travelTime`. Ships choose among allowed routes by expected profit per hour (greedy plus noise). Ships are autonomous agents with a simple state machine: Idle -> Load -> Sail -> Unload -> Idle.
- **Money**: shared "Treasury" is the player's company. Ship trade profit flows to it. A share goes to the island's prosperity.
- **Trade Points (TP)**: earned by delivered value; used with coin to unlock islands.
- **Progression gates**: ship tier unlocks need connected islands count plus cumulative trade value. Example: caique at 4 islands, ferry at 10, cargo at 20 plus a mainland port, charter at 30 plus tourism income.
- **Seasonality (light)**: tourism multiplier peaks in summer in game time.
- **Lit state**: an island is `dark -> connecting -> lit`. It becomes lit when its first successful delivery completes. Lit amount then drifts with prosperity (0.8–1.0 daylight, with lights intensity).

## Balancing Targets
- First delivery within 30 s of start.
- Second island unlocked by ~2 minutes, 10 islands by ~15 minutes, whole map by ~60–90 minutes at 1x/4x.
- Keep all tunables in `balance.json`.
