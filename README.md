# Aegean Tycoon v2

A 3D browser simulation of the rebirth of maritime trade in the Aegean Sea. The map starts as a dark, photoreal satellite night scene. Two islands begin trading with small fishing boats. Each island that joins the trade network lights up and turns to **daylight**. The network grows into a busy ecosystem of ferries, cargo ships and charter boats linking 50+ islands, the Greek mainland and Turkey.
